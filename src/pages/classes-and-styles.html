Classes & styles

nb-class adds and removes CSS classes, nb-style sets inline styles.

FormExample
Objectnb-class="{active: this.on; 'is-big': this.big}"
Stringnb-class="this.theme"
Arraynb-class="[this.size; this.theme]"
Stylesnb-style="color: this.color; width: this.w + 'px'"
  • Entries are separated with ; (write \; for a literal one). A comma is not a separator here.
  • A style value ending in !important is applied as important; null or undefined removes the property.
  • Classes written in the markup (class="card") are never removed by nb-class — leave a class out of the markup if a binding should switch it off.

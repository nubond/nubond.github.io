Lifecycle hooks

Implement any of these methods on a container or component; nuBond calls them. Watch the console below the result.

HookCalled
constructorWhen the entity is created — on first show, if its element starts hidden.
onInputsRefreshDone()After nb-in inputs changed.
onDetectChangesDone()After each pass of its template.
onDispose()Before it is destroyed — clear timers, unsubscribe here.
onContainerAttached(ctx)A container in this template was attached; ctx is the child's instance.
onContainerDetached(ctx)A container in this template was removed.

nb-container takes an expression, so the rendered container can change at runtime; an empty name removes it. Hiding with nb-if does not dispose — the instance is kept.

onContainerAttached is about child containers only: a context is never told about its own attachment, and components never raise it.

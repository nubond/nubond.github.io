Attributes & properties

nb-attr:name sets an HTML attribute, nb-prop:name sets a DOM property.

nb-attr:namenb-prop:name
WritessetAttribute(name, String(value))element[name] = value
Removeswhen the value is null or undefinednever — the value is assigned as is
Use forARIA, href, data-*, attributes CSS selects onchecked, disabled, value, objects for web components
  • Names are written in kebab-case and converted: nb-prop:read-only sets readOnly.
  • class, style, textContent and innerHTML are refused — use nb-class, nb-style, nb-value, nb-html.

A boolean attribute is on whenever it exists: nb-attr:disabled="this.locked" writes disabled="false", which disables. Write this.locked ? '' : null, or use nb-prop:disabled.

Registering what a template uses

Containers, components, aspects and transformers that appear only in markup must be passed to a decorator — that import is what registers them. @AppRoot, @Container and @Component all take them as arguments. Registrations go into the string array: $Template and $AdoptedStyle for @AppRoot and @Container; a component's array holds adopted styles (see Styles). Put each one where its scope is:

  • App-wide — shared templates and styles, aspects and transformers used everywhere: in @AppRoot or the main container.
  • Local — used by one container or component only: in that entity's own decorator, @Container(html, Counter), @Component(html, css, Badge).

The registry is global either way — the place just keeps the dependency next to its user. Forget it everywhere and the template fails at runtime with … not found, not at compile time.

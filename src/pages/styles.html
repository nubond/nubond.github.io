Styles & adopted styles

A component's CSS stays inside the component. To share CSS between components, register it once as an adopted style.

  • @Component(html, css) — the component's own CSS. :host is the element, :host([kind=warn]) the element with that attribute.
  • $AdoptedStyle('shared', css) registers a CSSStyleSheet once; components list the names they need: @Component(html, css, ['shared']). Aspects can list them too.
  • Register it in the array of an @AppRoot, @Container, @Component or @Aspect. $AdoptedStyle returns the name, so in a component or aspect it registers and adopts at once: @Component(html, css, [$AdoptedStyle('shared', sharedCss), 'theme']). Register each name only once and refer to it by name elsewhere. Names are resolved when the component or aspect is first built, so it does not matter which decorator registers the style.
  • CSS custom properties pass the shadow boundary — the simplest way to theme components from outside.
  • Containers have no Shadow DOM: page CSS styles them, and they need no adopted styles.

The arguments after the template are recognized by their type, not their position: a string is the CSS, an array the adopted style names, an object the config, a class a dependency.

Lists

nb-repeat="collection" repeats the element once per item. Inside, item, index and count describe the current row.

The collection is read live, so push and splice show up on the next pass. Put nb-if on the repeated element to filter rows: <li nb-repeat="this.todos" nb-if="!item.done">.

Nesting and other collections

Name a repeat to reach its variables from an inner one: nb-repeat:group provides groupItem, groupIndex and groupCount. Keep the name one lowercase word — it is not converted.

Collectionitem is
Array, typed array, Set, stringthe element / character
Mapa [key, value] pair
Objecteach property value (prefer arrays — they are faster)
Number N1 … N

Rows are reused by position, not by identity: row 3 always shows item 3. After sorting or removing, DOM state such as focus or an input's typed text stays with the position. For the same reason, avoid # bindings inside a list that changes.

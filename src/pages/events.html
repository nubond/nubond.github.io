Events

nb-event:name="expression" runs the expression when the element fires the event — then the view updates.

Debounce and once

  • nb-event:input:400 — a number after the event name debounces the handler by that many milliseconds.
  • nb-event:click="#this.start()" — the # prefix runs the handler once, then unsubscribes.
  • Any event works, custom ones included: nb-event:item-selected, nb-event:plugin:ready.

What a handler can use

NameValue
eventThe DOM event.
dataevent.detail — the payload of a custom event.
nativeElementThe DOM element.
elementHelpers for that element: styles, classes, attributes, properties.
unSubscribeA function that stops this handler.
routerThe router, when routing is configured.

Every handler run triggers a change-detection pass. Do not bind events that fire constantly — pointermove, scroll, dragover — with nb-event; see the Aspects example for the alternative.

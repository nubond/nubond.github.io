Routing

Describe the URL with a route template, render the current page with nb-container="%slot", navigate with router.go().

The route template

  • A [slot] holds a container name; the container with that name renders into nb-container="%slot".
  • A {slot} holds any value, read from router.state.slot — always a string.
  • A container slot set to a name that is not a registered container is refused with an error and keeps its value.
  • When a slot is empty, the slots after it go into the query string: #/profile?tab=posts.
  • In hash mode plain links route too: <a href="#/profile/ada">.
  • Path mode (no #) owns the whole path — serve the app from the root of its domain.

The router

onBeforeStateChange(cb)cb(prevent, oldState, newState) — call prevent() to cancel.

In nb-event handlers the router is simply router. Anywhere else, inject it: constructor(public router: Router).

Router methods throw when no route template was given — the only part of nuBond that does not just log. Check router.isConfigured when routing is optional.

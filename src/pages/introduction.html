Hello, nuBond

nuBond is a small TypeScript framework for web apps: plain classes with decorators, HTML templates with nb-* attributes, real Web Components. No runtime dependencies.

The basics · 15 min Templates, events, lists, containers and components — enough to build an app. Everything else · 15 min Change detection, DI, routing, aspects, transformers, projection, configuration.

Your first app

A class decorated with @AppRoot() becomes the app. Its markup is the page (index.html), and every expression in it runs against the class instance — this.

Every example on this site is editable. Change the code — the result re-runs as you type. Ctrl+Enter runs it right away, the reset button restores the original.

The building blocks

DecoratorWhat it is
@AppRootStarts the app on an existing element (default: <body>).
@ContainerA class + template rendered inline. Use it for pages and sections.
@ComponentA class + template + CSS as a custom element with Shadow DOM.
@AspectA behavior you attach to any element.
@TransformerA global function callable from any template expression.
@InjectableA service delivered through constructor injection.

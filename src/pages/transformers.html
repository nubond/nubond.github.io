Transformers

A transformer is a global function for templates: formatting, translation, small calculations.

  • The function name is the class name with a lowercase first letter: Currency → currency(…). Or name it: @Transformer('money').
  • Every argument of the call is passed to transform().
  • One instance serves the whole app, and it can inject services — e.g. a localization service for t('save').
  • Errors in transform() are logged and the call returns undefined.
  • Names are case-insensitive and unique, and cannot be one of the built-in names (item, index, count, event, data, element, nativeElement, unSubscribe, router).
  • An nb-var name or a repeat prefix that collides with a transformer name is rejected with an error.

For text that never changes, freeze it: {{ #t('title') }} runs the transformer once instead of on every pass.

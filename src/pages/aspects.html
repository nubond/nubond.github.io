Aspects

An aspect adds behavior to an existing element — any element, with no new template and no new scope. Attach one with nb-aspect:name="value".

  • The name is the kebab-cased class name: Badge → nb-aspect:badge.
  • The bound value arrives in the data setter whenever it changes. Always add a data getter — nuBond compares against it, and without one the setter runs on every pass.
  • An aspect can inject the host element, ElementManipulations, ElementSubscriptions, ChangeDetector and EventDispatcher.
  • Its CSS (the first decorator argument) is added to the document, or to the shadow root the element lives in.
  • Aspects are created even on hidden elements.

Spotlight shows how to handle constant events: ElementSubscriptions is a plain listener that never triggers a pass. Update visuals directly, and call detect() only when something worth rendering settles.

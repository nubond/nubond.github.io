Conditionals

nb-if shows an element while its expression is truthy. nb-switch shows the one nb-case that matches.

  • Hidden elements stay in the DOM with an nb-hidden class (display: none). Their children are not evaluated, so hidden markup costs almost nothing.
  • A container or component on a hidden element is created only when it is first shown, and is kept when hidden again.
  • nb-default takes no value and shows when no case matches.

Matching is type-strict

Cases compare with ===. @5 is the number 5, so it does not match the string '5' — values from the router, inputs and URLs are strings. Objects and arrays are compared by their JSON.

Variables & DOM access

Three small attributes for the remaining jobs: name a value, run code on every pass, get hold of an element.

AttributeDoes
nb-var:name="expr"Evaluates once per pass and exposes the result as name to the element and its children. Several on one element see each other left to right. nb-var:unit-price becomes unitPrice.
nb-exec="expr"Runs on every pass; renders nothing.
nb-bound="expr"Runs once, when the element is bound, with nativeElement and element — keep a reference, start a chart, focus a field.

nb-var is also a cache: a costly getter used ten times inside an element runs once per pass when you put it in a variable.

Variable names cannot reuse the built-in ones: item, index, count, event, data, element, nativeElement, unSubscribe, router.

Tooling

  • create-nubond — scaffolds a Parcel + TypeScript project (blank, native, showcase) with the generators above.
  • @nubond/posthtml-value-interpolation — the build step behind {{ }}. For W3C mode, set "nubond": { "compliantWithW3CInterpolation": true } in package.json.
  • Parcel setup — any .html / .scss / .css file imports as a string, except the entry files index.* and app.*, which Parcel bundles. Prefix a URL with ref: (href="ref:npm:pkg/x.css") to link a file instead of inlining it.
  • One file — nuBond has no runtime dependencies, so an app can be bundled into a single JavaScript file.
  • nuBond Language Service for VS Code — completion, hover, go to definition, rename and diagnostics inside templates. Enable it with "nubond": { "languageService": true } in package.json.

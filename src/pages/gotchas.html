Gotchas

The mistakes everyone makes once. nuBond reports problems with nuBond: messages in the console instead of throwing — keep it open.

SymptomCause and fix
A region stays empty, … not foundThe entity is used only in markup and was never imported. Pass it to the decorator of the container or component that uses it — or to @AppRoot if it is used app-wide: @Container(html, MyCard, Tooltip).
An input or variable is always undefinedHTML lowercases attribute names: write nb-in:user-name, not nb-in:userName. Repeat prefixes are not converted at all — keep them one lowercase word.
The view does not updateNothing triggered a pass: a timer, a promise or a service changed the data. Use @Detector() or detect().
@Detector() does not fireThe object was mutated, not replaced. Assign a new one.
An expression always returns undefinedA ; in the expression — separate statements with commas.
A control is disabled forevernb-attr:disabled="false" still disables. Use cond ? '' : null or nb-prop.
nb-case never matchesType mismatch: @5 is a number, route and input values are strings — write nb-case="'5'".
An nb-in value arrives as undefinedIt cannot be cloned (a function, a DOM node). Use nb-in-ref.
A child's DOM is stale after an editWith nb-in-ref an in-place change is invisible. Assign a new object.
A parent never hears an eventCustom events do not bubble, and HTML lowercases names: dispatch item-selected, not itemSelected.
A service arrives as undefinedThe parameter is typed with an interface, any or a union. Use a class.
Wrong row state after sortingnb-repeat reuses rows by position. Keep per-row state in the data, not in the DOM.
Projected markup sees the wrong thisProjected content binds in the receiving template. Pass data with nb-in.
A component built by hand is emptyComponents start only inside a nuBond template, never via document.createElement.
A class is missing after minificationnuBond uses class names. Keep them (keep_classnames) or give entities explicit names.
Bindings on one element are dropped with an errorSome cannot share an element: only one of nb-value, nb-html, nb-switch, nb-container, a component tag, nb-template; and nb-case / nb-default exclude nb-repeat and nb-if. Nest an element instead.
multiple handlers for one … are not supportedTwo attributes target the same thing (nb-event:click:100 + nb-event:click:200, nb-in:x + nb-in-ref:x). The first wins.
template '…' not found$Template ran after the element using it was built. Register it in the array of the @AppRoot or @Container that uses it — @Container(html, [$Template(…)]) — or, for a component, of its parent.

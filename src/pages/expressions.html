Expressions

Every nb-* value is a JavaScript expression evaluated against your class. A prefix changes how often it runs.

PrefixMeaning
noneRe-evaluated on every change-detection pass.
#One-time: evaluated until the first result that is not undefined, then frozen.
@A constant, never evaluated: @true is a boolean, @5 a number, anything else a string (@Save → "Save").
%A route slot — only in nb-container, see Routing.

Rules

  • Reach your class through this: this.name, this.save().
  • Anything JavaScript allows works: template literals, ternaries, arrow functions, method calls.
  • Separate statements with a comma: this.a = 1, this.b = 2. A ; breaks the expression.
  • Expressions are strings, so the compiler cannot check them. A failing expression is logged to the console, not thrown.

Use # for anything that never changes after it is first known — labels, translations, constants built in the constructor. Fewer live expressions make every pass cheaper.

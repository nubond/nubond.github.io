Dependency injection

Ask for a service in the constructor — nuBond creates it and passes it in, looked up by the parameter's class.

Both components receive the same Cart because it is a singleton. Adding an item runs a pass in <product-list> only, so <cart-badge> listens to the service and calls detect() itself — the usual pattern for shared state.

Registering services

Your own services resolve everywhere, transformers included. Dependencies are resolved recursively; a circular reference is reported in the console.

Type parameters with a class. An interface, any or a union type compiles to Object and is not injected (Injection 'Object' cannot be resolve.).

Give every decorated class its own constructor — an inherited one receives no injections. Services (@Injectable) cannot receive ChangeDetector and friends: those belong to a template.

Components

A component is a real custom element: a class, a template and CSS, isolated in Shadow DOM. Use components for reusable widgets.

The rules

  • The tag is the kebab-cased class name: StarRating → <star-rating>. It must contain a hyphen; give single-word classes a name: @Component(['my-button', html], css).
  • In the example, nb-in:value and nb-in:max are inputs and the rate event an output — exactly as for containers, see below.
  • The component's CSS applies only inside it, and page CSS does not get in. Style the element itself with :host.
  • The Shadow DOM is closed by default: code outside cannot reach in, so inputs and outputs are the way to talk to a component.
  • Components come alive only inside a nuBond template — document.createElement('star-rating') stays an empty element.

The element itself

Pass a class extending HTMLElement and the component's element is built from it — the place for observedAttributes, form association or other native behavior. Inject it to reach the element from the context. A config object sets the shadow root for this component only, replacing the app-wide default ($GlobalShadowRootConfig).

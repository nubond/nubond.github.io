Containers

A container is a class with its own template, rendered inside an element with nb-container. Use containers for pages and sections.

How it fits together

  • @Container(html) registers the class; nb-container="@Counter" renders it (names are case-insensitive).
  • In the example, nb-in:start is an input and the reached event an output — see below.
  • A container has no Shadow DOM: page CSS applies to it.

Where a template can come from

The same forms work for component templates and styles, aspect styles, $Template and $AdoptedStyle. A string is fetched only when it starts with / and is a single line without < or {.

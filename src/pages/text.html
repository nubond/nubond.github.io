Text & HTML

Put values into the page with {{ expression }}, or with the nb-value and nb-html attributes.

WriteResult
{{ expr }}Text, mixed freely with literal text. The default choice.
nb-value="expr"The element's textContent. {{ expr }} compiles to <span nb-value="expr">.
nb-html="expr"The element's innerHTML.

Values are converted to text: null and undefined become an empty string, objects and arrays become JSON.

nb-html is not sanitized unless you register an htmlSanitizer — never feed it user input as is. See Configuration & security.

{{ }} is a build step (a PostHTML plugin, preconfigured by npm create nubond). Inside <option>, <title> and <textarea> — elements that cannot hold a <span> — use nb-value instead.

In W3C mode, add "nubond": { "compliantWithW3CInterpolation": true } to package.json — {{ }} then compiles to <span data-nb-value="expr">. Without it, the spans stay empty.
